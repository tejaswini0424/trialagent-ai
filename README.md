# TrialAgent AI

A multi-agent research framework for clinical trial protocol analysis and regulatory documentation review.

**Live application:** https://trialagent-ai.vercel.app

The full source, installation instructions, architecture, testing, and deployment documentation are in [TrialAgent_AI/README.md](TrialAgent_AI/README.md).

## Quick start

```bash
cd TrialAgent_AI
pip install -r requirements.txt
streamlit run app.py
```

The project includes seven specialized agents, a Streamlit dashboard, a FastAPI web edition, authenticated user-specific storage, PDF/DOCX/TXT extraction, evidence-linked findings, and PDF/CSV/JSON reports.

Research and education only. Automated findings require professional review and do not certify regulatory compliance. The included sample protocol is synthetic.
